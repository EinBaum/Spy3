# Spy3

EinBaum edit of [Spy Classic](https://www.curseforge.com/wow/addons/spy-classic) for **WoW Forever**.

Right click the GUI to clear the list.

Move the list in **Edit Mode** (Esc → Edit Mode). `/spy3 reset` recenters it.

Forever loads `Spy3_Camelot.toc` (`## Interface: 16001`). Character names are given name + surname. There are no realm names.

```
/spy3 reset
/spy3 test
```
